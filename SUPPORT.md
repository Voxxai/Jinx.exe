# Support

Jinx.exe is an early-stage passion project rather than a supported commercial product.

- Use [GitHub Discussions](https://github.com/Voxxai/Jinx.exe/discussions) for questions,
  setup help and ideas that are not yet actionable feature requests.
- Use the issue forms for reproducible bugs and focused feature proposals.
- Use [private vulnerability reporting](https://github.com/Voxxai/Jinx.exe/security/advisories/new)
  for security issues.

Never post access tokens, viewer data, stream keys or other personal information publicly.
