# Roadmap

## Phase 1 — Foundation

- [x] Tauri, React and TypeScript foundation
- [x] Event-to-reaction domain model
- [x] Automated quality and security checks
- [x] Manual reaction console
- [x] Persisted local settings
- [ ] Transparent, click-through companion window

## Phase 2 — Stream awareness

- [ ] Twitch OAuth with minimum required scopes
- [ ] Twitch EventSub WebSocket client
- [ ] Follow, subscription and raid reactions
- [ ] OBS WebSocket connection and scene state
- [ ] Global cooldown and event priority queue

## Phase 3 — Personality

- [ ] Animation state machine
- [ ] Moderated and rate-limited TTS
- [ ] Mood and energy system
- [ ] User-authored reaction packs
- [ ] Stream Deck triggers

## Phase 4 — Ecosystem

- [ ] Spotify-aware music states
- [ ] Plugin/event SDK
- [ ] Signed desktop releases for supported platforms
- [ ] Import/export for configuration profiles
- [ ] Optional anonymous crash reports with explicit opt-in
